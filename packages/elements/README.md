# @hearth-ui/elements

Framework-independent web components for self-hosted dashboards, public pages, and authentication. **70 components**, including seven page recipes, five palettes, and one shared design language.

New in v0.5.0: timeline, theme switcher, number input, time picker, calendar, date picker, date-range picker, range slider, and stepper.

[Showcase](https://hearth-ui.samyx.net/) · [HTML example](https://hearth-ui.samyx.net/elements.html) · [React example](https://hearth-ui.samyx.net/react.html) · [Agent index](https://hearth-ui.samyx.net/llms.txt)

## Install

After registry publication:

```sh
npm install @hearth-ui/elements
```

Before publication, install the matching `hearth-ui-elements-<version>.tgz` generated by the repository's `npm run pack:packages` command.

```js
import { registerElements } from "@hearth-ui/elements";
import "@hearth-ui/elements/themes.css";

registerElements();
```

```html
<hearth-theme theme="sunset" mode="dark">
  <hearth-auth-page brand="homestead"></hearth-auth-page>
</hearth-theme>
```

```js
document
  .querySelector("hearth-auth-page")
  .addEventListener("submit", (event) => {
    const [{ username, password }] = event.detail;
    // Call your auth API. Do not log or store credentials.
  });
```

Or import `@hearth-ui/elements/auto` for automatic registration. Individual constructors and `registerElements('my-app')` are available for explicit registration and custom tag prefixes.

## No Vue dependency in the host

The Vue runtime is bundled once into the element distribution. This package has **no runtime dependencies or Vue peer dependency**, and its TypeScript declarations use DOM types rather than Vue types. No global Vue or Node variables are required in the browser.

For plain HTML without a bundler, serve the extracted package contents:

```html
<link rel="stylesheet" href="./dist/themes.css" />
<script type="module" src="./dist/elements/auto.js"></script>
<hearth-button variant="primary">Save</hearth-button>
```

Keep all files in `dist/elements/` together because the entry points import shared chunks.

## Integration rules

- Arrays/objects are DOM properties, not JSON attributes.
- Boolean attributes use presence/absence. Use `.disabled = false` instead of `disabled="false"`.
- Vue-emitted events use argument arrays in `event.detail`; native `click` retains its normal MouseEvent payload.
- Listen directly on the element. Native slots use `slot="name"`.
- Inputs participate in their owning HTML form. Use `FormData.getAll(name)` for multi-select values.
- Theme through inherited `--h-*` custom properties, `themes.css`, and exposed CSS parts.
- Elements render when connected in a browser. For server-rendered component content, use `@hearth-ui/vue`.

Current browsers need Custom Elements, Shadow DOM, ElementInternals, native dialog, and modern CSS support. Component styles are injected into shadow roots; configure your CSP for that styling model.
