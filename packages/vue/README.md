# @hearth-ui/vue

Native Vue 3 components for self-hosted dashboards, public pages, and authentication. **70 components**, including six page recipes, five palettes, and one shared design language.

New in v0.5.0: `HTimeline`, `HThemeSwitcher`, `HNumberInput`, `HTimePicker`, `HCalendar`, `HDatePicker`, `HDateRangePicker`, `HRangeSlider`, and `HStepper`.

[Showcase](https://hearth-ui.samyx.net/) · [Component guide](https://hearth-ui.samyx.net/#components) · [Agent index](https://hearth-ui.samyx.net/llms.txt)

## Install

After registry publication:

```sh
npm install @hearth-ui/vue vue
```

Before publication, install the matching `hearth-ui-vue-<version>.tgz` generated by the repository's `npm run pack:packages` command.

```vue
<script setup lang="ts">
import { HTheme, HAuthPage, type AuthCredentials } from "@hearth-ui/vue";
import "@hearth-ui/vue/styles.css";

function signIn(credentials: AuthCredentials) {
  // Call your application's authentication API.
}
</script>

<template>
  <HTheme theme="sunset" mode="dark">
    <HAuthPage brand="homestead" @submit="signIn" />
  </HTheme>
</template>
```

Vue 3.5+ is a peer dependency. The JavaScript uses your application's Vue runtime. Import `styles.css` once for component styles and tokens. `themes.css` is also exported for token-only use.

## Included

- Native Vue components with typed props, slots, events, and `v-model`.
- Public/dashboard shells, auth page, cards, controls, comboboxes, navigation, and feedback components.
- Sunset, Ocean, Forest, Dusk, and Rose; dark/light/system modes and density settings.
- Theme helpers and types, source-derived `llms.txt` references, and SSR-compatible rendering.

Authentication, routing, storage, and network requests remain application concerns. This package contains native Vue components; use **`@hearth-ui/elements`** for web components.
